🔬 Metodología del Análisis

1. Fuente de Datos

  • Datos del SRI: RUCs, razones sociales, estados, ubicaciones
  • Google Maps API: Reseñas, calificaciones, presencia online
  • Filtro: Solo librerías con estado ACTIVO

2. Proceso de Búsqueda

  • Búsqueda automática en Google Places API usando nombre y ubicación
  • 58 de 62 librerías encontradas (93.5%)
  • Obtención de reseñas, calificaciones, sitio web, teléfono

3. Cálculo de Estimaciones

Las estimaciones se basan en múltiples indicadores:

  • Número de reseñas: Más reseñas = más actividad = más ventas estimadas
  • Calificación: Mejor calificación = más confianza = más ventas
  • Sitio web: Presencia online = más alcance = más ventas
  • Estado del contribuyente: ACTIVO = operando = más ventas

4. Análisis de Libros

  • Google Books API: Búsqueda de libros relacionados con cada librería
  • Búsqueda: Se utilizan queries basadas en nombre de librería, ubicación y términos relacionados
  • Cobertura: Se analizaron todas las 58 librerías filtradas (no solo las con sitio web)
  • Obtención de precios:
    • Primero se intenta obtener retailPrice de Google Books
    • Si no está disponible, se intenta listPrice
    • Si no hay precio disponible, se estima basándose en:
      • Número de páginas del libro
      • Categoría (técnico, ficción, infantil, etc.)
      • Rango típico en Ecuador: $5-25 USD
  • Links: Se incluyen links a Google Books y sitios web de librerías cuando están disponibles

5. Fórmula de Estimación de Ventas

⚠️ Importante: La fórmula de estimación fue desarrollada basándose en datos reales de ventas obtenidos de algunas librerías consultadas directamente o a través de fuentes oficiales. Estos datos reales sirvieron como punto de referencia para calibrar los rangos de estimación según diferentes indicadores.

Base según reseñas (calibrada con datos reales):

  • 0-10 reseñas → $5,000-15,000 USD/mes
  • 11-50 reseñas → $15,000-40,000 USD/mes
  • 51-100 reseñas → $40,000-80,000 USD/mes
  • 100+ reseñas → $80,000-150,000 USD/mes

Ajustes (derivados de correlaciones encontradas en datos reales):

  • Calificación 4.5+ → +30% (librerías con mejor calificación mostraron ventas ~30% superiores)
  • Calificación 4.0-4.5 → +10% (calificación media correlaciona con ventas ligeramente superiores)
  • Con sitio web → +50% (presencia online mostró impacto significativo en ventas reales)
  • Estado ACTIVO → +20% (librerías activas vs suspendidas mostraron diferencia promedio del 20%)

Nota metodológica: Los rangos y porcentajes fueron ajustados comparando las estimaciones iniciales con los datos reales disponibles, permitiendo una calibración más precisa del modelo. Sin embargo, estas estimaciones siguen siendo aproximaciones y pueden variar según factores específicos de cada librería.

⚠️ Limitaciones y Consideraciones

📅 Sobre las Fechas de las Reseñas

  • Las reseñas son el total acumulado hasta hoy
  • NO tenemos fechas específicas de cada reseña
  • No sabemos si son de este mes, este año, o de varios años
  • Son una "foto" del estado actual, no un historial

💰 Sobre las Estimaciones de Ventas

  • Son proyecciones mensuales/anuales basadas en el estado actual
  • NO son datos históricos reales de ventas
  • No corresponden a un período específico (diciembre 2024, etc.)
  • Son estimaciones de lo que podría vender mensualmente

📊 Otras Limitaciones

  • 4 librerías no fueron encontradas en Google Maps
  • Las reseñas pueden no reflejar ventas directamente
  • Algunas librerías pueden tener muchas reseñas pero pocas ventas (o viceversa)
  • Las estimaciones pueden estar sobreestimadas o subestimadas
  • Para datos reales, se requiere consultar el SRI o las librerías directamente

💡 Recomendaciones

  • Consultar el SRI para obtener datos oficiales de facturación
  • Contactar directamente a las librerías para validar estimaciones
  • Usar estas estimaciones como referencia comparativa, no como valores exactos
  • Actualizar periódicamente con nuevos datos
