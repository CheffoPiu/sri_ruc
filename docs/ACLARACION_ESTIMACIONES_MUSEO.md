## ⚠️ Limitaciones de las Estimaciones

### Son aproximaciones, NO datos reales:

1. **Basadas en indicadores indirectos:**
   - Reseñas no = ventas directas
   - Una librería puede tener muchas reseñas pero pocas ventas (o viceversa)

2. **No consideran:**
   - Precios reales de los libros
   - Volumen de inventario
   - Estacionalidad (épocas de alta/baja demanda)
   - Competencia local
   - Tamaño físico del local

3. **Para datos reales necesitas:**
   - Consultar el SRI (declaraciones de IVA)
   - Contactar directamente a las librerías
   - Ver estados financieros (si son públicos)

## 💡 Recomendaciones

### Para mejorar las estimaciones:

1. **Validar con datos reales:**
   - Consultar SRI para obtener facturación real
   - Comparar con estimaciones para ajustar el modelo

2. **Ajustar el modelo:**
   - Si encuentras que las estimaciones están muy altas/bajas, ajusta los multiplicadores
   - Considera factores adicionales (ubicación, tamaño, etc.)

3. **Usar como referencia comparativa:**
   - Las estimaciones son útiles para **comparar** librerías entre sí
   - No las uses como valores absolutos
